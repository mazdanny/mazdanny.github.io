Tata Bahasa: Isim Isyarah & Kepemilikan (ـي / -ku)

1. Laki-laki / Mudzakar (هٰذَا)

Gunakan kata tunjuk هٰذَا (Ini) ditambah akhiran ـي untuk menyatakan kepemilikan (ku).

هٰذَا أَبِي / هٰذَا جَدِّي

"Ini Ayahku / Ini Kakekku"

2. Perempuan / Muannats (هٰذِهِ)

Gunakan kata tunjuk هٰذِهِ (Ini) ditambah akhiran ـي untuk menyatakan kepemilikan (ku).

هٰذِهِ أُمِّي / هٰذِهِ جَدَّتِي

"Ini Ibuku / Ini Nenekku"
